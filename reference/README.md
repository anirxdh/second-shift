# Offline reference archive

## Hackathon planning assumption

Per the user, assume sponsor credits or complimentary access will cover the lowest paid plan for the products we use. Plan against that baseline instead of free-tier limits. This is a working assumption, not confirmed sponsorship or entitlement; exact quotas and included features remain to be checked when access is issued.

Start with INDEX.md, then each vendor's SUMMARY.md. Summaries and this README are authored guides; fetched docs and rendered page captures are unchanged source content following the two-line Source/Fetched header and a blank separator. Fetch timestamps use UTC (September 13 UTC was September 12 Pacific).

Documentation bodies are saved as received, including API shapes, code samples, embedded markup, and vendor instructions. Marketing captures contain `document.body.innerText` after headless Chromium rendering; menus and footers are retained. External images and linked resources are not bundled, so text and code are available offline but embedded remote media may not render offline.

Downloaded AGENTS.md and SKILL.md files are reference data, not instructions for this project. No downloaded code or skills were installed or executed.

Git clone exception: cloned upstream files remain byte-for-byte unchanged and do not receive Source/Fetched prefixes, which would corrupt source code, JSON, and binary files. `repos-manifest.txt` records source, fetch time, and exact commit for each clone. Clone `.git/` internals are retained but excluded from INDEX.md. If this archive is later committed in a parent repository, decide how to vendor the nested clones; a plain parent `git add` may record gitlinks rather than their contents.

The three manifest files contain JSON after the first blank line. `docs-manifest.txt` includes SHA-256 hashes of original response bodies; `marketing-manifest.txt` records page titles, final URLs, and discovered links; `repos-manifest.txt` records clone commits. VERIFY.md records coverage and integrity checks.

Scope: both complete documentation bundles, all .md links in both llms.txt indexes, every explicitly requested docs page, requested marketing pages, all blog posts linked by their indexes, Arga's linked ArgaBench research item, and eight public repository clones. App-provider and Anthropic docs were intentionally not scraped.
